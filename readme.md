# Taco Tom’s Lonchera

A full-stack restaurant website built for Taco Tom’s Lonchera. The site provides customers with restaurant information and an accessible online menu, while giving authorized administrators tools to manage menu items and images.

🔗 **Live site:** https://tacotomslonchera.com
📁 **Portfolio:** [Jasmine Biri Portfolio](https://jbiri03.github.io/portfolio/index.html)

## Preview

![Screenshot of the Taco Tom's Lonchera website](/images/taco_tom_home.png)

## Features

### Public Site

- View restaurant information
- Browse the online menu
- View menu items and images
- Responsive design for desktop and mobile devices

### Admin Features

- Secure admin login
- Create, edit, and delete menu items
- Upload and manage menu-item images
- Update menu content through an admin-facing dashboard

## Built With

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Image Storage:** Cloudflare R2
- **Deployment:** Fly.io
- **Version Control:** Git and GitHub


## What I Built

This project was created to build experience with full-stack web development and deployment. Key areas of focus included:

- Designing a database-driven menu system
- Building REST-style backend routes with Express
- Managing administrator authentication and sessions
- Integrating Cloudflare R2 for image storage
- Deploying a Node.js application to Fly.io
